### Overview

**MassDM** is the ultimate direct messaging tool for Minecraft 1.21.4. It is a lightweight, feature-packed utility mod designed to automate communication and make server-wide interaction effortless.

---

### 📊 Quick Info

| Feature | Details |
| :--- | :--- |
| **Game Version** | Minecraft 1.21.4 |
| **Mod Loader** | Fabric |
| **Environment** | Client-side only (Works on any server!) |
| **Supported Languages** | 🇬🇧 English, 🇵🇱 Polish, 🇩🇪 German |

---

### ✨ Key Features

* **Player Counting & Listing:** Easily check the list of online players on any server.
* **Automated Direct Messaging:** Send custom direct messages (`/msg`) to every player automatically.
* **Custom Delay Support:** Set custom delays between messages to prevent spam flags and control broadcast speed.
* **Instant Process Control:** Cancel ongoing message broadcasts at any time with a single command or GUI click.
* **In-Game Graphical User Interface:** Convenient GUI accessible directly via a hotkey or pause menu.
* **Interactive Exclusion List:** Easily manage excluded players directly in the GUI with an online player list and one-click "Exclude" buttons.
* **Favorite Message Presets:** Save and quickly load your most frequently used direct messages using the ⭐ button.
* **Audio Notifications:** Sound alerts when a message broadcast starts and finishes.
* **Multilingual Support:** Fully translated into **English**, **Polish**, and **German** (auto-detects your game language!).

---

### 🚀 How It Works

1. **Open the Interface:** Press **`J`** in-game or open the menu via **`ESC`**.
2. **Set Your Message & Delay:** Enter the text you want to send and adjust the interval (e.g., `2` seconds between players).
3. **Start Broadcasting:** Click **Send** and let MassDM automatically message players on the server!
4. **Emergency Stop:** Hit **Stop** at any time to freeze the queue instantly.

### ⚡ Commands

| Command | Description |
| :--- | :--- |
| `/massdm help` | Displays the help menu and available commands. |
| `/massdm list` | Displays the current list of online players on the server. |
| `/massdm send <delay> <msg>` | Sends a direct message to all online players with a specified delay (in seconds). |
| `/massdm stop` | Instantly stops the active message sending process.
