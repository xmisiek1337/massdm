# 🚀 Update Release - v1.1.0

Welcome to the major v1.1 update for **MassDM**! This release brings a massive overhaul to the graphical interface, introduces powerful message templates, and adds highly requested quality-of-life features.

### ✨ What's New in v1.1:
* **Fully Redesigned GUI Layout:** The interface is now perfectly centered, clean, and optimized for screens of all sizes.
* **Interactive Exclusion List:** You can now manage excluded players directly in the GUI using the new "Online Players" screen with one-click "Exclude" buttons!
* **Favorite Message Presets:** We've added a new `★` button to save and quickly load your most frequently used direct messages.
* **Smart Placeholders:** You can now use advanced placeholders in your messages (e.g., `{player}`, `{me}`, `{time}`, `{server}`, `{ping}`, and even `{random:10}`) to bypass anti-spam and personalize content.
* **Audio Notifications:** Added helpful sound alerts when a message broadcast starts and successfully finishes.
* **Server-Specific Profiles:** Your excluded player lists and configurations are now saved separately for each server you join!
* **Multilingual Support:** The mod is now fully translated into **🇬🇧 English**, **🇵🇱 Polish**, and **🇩🇪 German**!
* **Head-Up Display (HUD):** Added a minimal, togglable HUD overlay that shows the progress of active mass messaging.
* **Quick Actions:** Added handy buttons like "Refresh List", "Copy List", and "Repeat Last" directly in the main GUI.

### 🐛 Bug Fixes & Adjustments:
* **Fixed List Gaps:** Fixed the annoying bug that caused massive empty vertical gaps between names in the player lists.
* **Removed Auto-Responder:** The auto-responder has been removed for better performance and a cleaner codebase.
* **Improved Background Blur:** Optimized background rendering so that it works nicely with blur mods like Blur/MenuBlur.
